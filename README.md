# UstaHub

```
ustahub/
  backend/     → API (Node.js + Express + SQLite)
  frontend/    → Mijoz + Admin UI
```

## Ishga tushirish

```bash
cd backend
npm install
cp .env.example .env
node server.js
```

Brauzer: http://localhost:3000

Backend frontendni o'zi xizmat qiladi (bitta port).
